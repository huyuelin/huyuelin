## Selected work

### GAC: Noise-Aware Adaptive Mixing for Hybrid SFT-RL Post-Training

**First author · Accepted to EMNLP 2026 Main Conference**

GAC adaptively balances supervised fine-tuning and reinforcement learning using a noise-aware mixing controller. The project includes a reference implementation, a public model checkpoint, and a versioned evaluation profile.

I was responsible for GAC's method design, theoretical derivations, training implementation, experiments, and open-source maintenance.

[Paper](https://arxiv.org/abs/2605.26184) · [Code](https://github.com/deepnovacore/GAC) · [Project page](https://deepnovacore.github.io/GAC/) · [Model](https://huggingface.co/YueLinHu/GAC-Qwen3.5-4B) · [Evaluation profile](https://github.com/deepnovacore/GAC/tree/main/eval/profiles/gac_release_20261008)
